# WebCraft 网页工坊

WebCraft 网页工坊是一款 Chrome MV3 扩展，用来把网页上的截图、录屏、翻译、YouTube 素材下载和资料采集集中到一个工具里。它适合做网页取证、内容整理、视频封面收集、AI 生成结果归档、多语言阅读和网页资料收藏。

## 功能介绍

### 截图与长截图

- 可截取当前可视区域，并自动下载为 JPG 或 PDF。
- 支持长截图/滚动截图，可从页面顶部开始，也可以从当前位置开始。
- 文件名支持组合工具名、名称和日期，默认形如 `截图凭证-{tool}-{name}-{date}`。
- 支持快捷键 `Ctrl+Shift+S`，macOS 为 `Command+Shift+S`。

### 区域录屏

- 可在当前网页上拖拽选择录制区域，只录制选中的页面区域。
- 会记住上一次录制区域，方便连续录制同一位置。
- 录制时提供暂停、继续和停止控制。
- 支持录制边框显示、最长录制时长和最大文件体积保护。
- 录制完成后自动导出 WebM 视频。

### 翻译增强

- 支持 Google Translate 快速翻译，无需 API Key。
- 支持 DeepL API，可在设置页填写 Auth Key。
- 支持右侧翻译入口打开独立扩展窗口、选中文本翻译、输入框快捷翻译。
- 支持自动中英互译，也可以指定中文、英语、日语、韩语、法语、德语、西班牙语、俄语、波兰语、瑞典语、匈牙利语、克罗地亚语、保加利亚语等目标语言。
- 可保存翻译历史和常用短语。

### 采集画布

- 可收集网页中的选中文本、图片、链接和当前网页信息。
- 支持右侧悬浮画布入口。
- 支持按全部、图片、文字、网页、链接筛选。
- 支持搜索、导出和导入采集内容。
- 可通过快捷键 `Ctrl+Q` 打开或关闭画布，macOS 为 `Command+Shift+Y`。

### YouTube 工具

- 可粘贴单个 YouTube 视频链接下载高清缩略图。
- 可输入频道、列表或主页链接批量分析并下载缩略图。
- 在 YouTube 页面中自动给视频卡片和播放器区域添加快捷按钮。
- 支持截取当前 YouTube 单帧。
- 支持录制当前 YouTube 播放器区域视频。
- 支持隐藏 Shorts、直播、广告位和评论区的 YouTube 自带翻译按钮。
- 支持推荐区模式：开启、关闭或仅保留白名单频道。

### 以图搜图

- 在网页图片上右键，可使用 Google Lens、Bing Visual Search、Yandex Images 搜图。
- 也可以一次性打开多个搜图入口，便于对比结果。

### 配置备份

- 设置页支持导出和导入已知配置项；翻译历史与采集画布需分别管理，不会进入配置备份。
- DeepL API Key 保存在浏览器扩展本地存储中，不会写入新导出的配置文件；迁移后需重新填写。
- 采集画布、翻译窗口和选中文字译文显示在独立扩展窗口中；已放入普通网页输入框的内容仍受该网页本身的脚本控制。

## 安装教程

1. 打开 Chrome 或 Arc 浏览器。
2. 进入 `chrome://extensions/`。
3. 开启右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择本项目文件夹。
6. 浏览器工具栏中出现 WebCraft 图标后，点击即可打开插件面板。

## 基础使用教程

### 1. 截取当前网页可视区域

1. 打开需要截图的网页。
2. 点击浏览器工具栏中的 WebCraft 图标。
3. 在“截图/录屏”页签中填写“名称”，例如项目名、客户名或素材名。
4. 选择生成工具，例如 Midjourney 生成、Firefly 生成、购买 Gemini 生成、Flow Ultra 版或 Flow Pro 版。
5. 选择保存格式：JPG 图片或 PDF 文档。
6. 点击“可视”。
7. 文件会自动下载到浏览器默认下载目录。

也可以直接按 `Ctrl+Shift+S` 快速截取当前可视区域。

### 2. 截取长网页

1. 打开目标网页。
2. 打开 WebCraft 面板。
3. 填写名称、选择工具和保存格式。
4. 如需从当前位置开始截图，打开“从当前位置开始”开关。
5. 点击“长图”。
6. 插件会滚动页面并生成长截图。
7. 如果启用了手动模式，可以在页面上的截图控制条中停止截图。

长截图适合保存长文章、聊天记录、瀑布流作品页、后台列表和完整网页证据。

### 3. 录制网页指定区域

1. 打开目标网页。
2. 打开 WebCraft 面板。
3. 在“截图/录屏”页签中填写名称并选择工具。
4. 点击“录屏”。
5. 在页面中拖拽选择需要录制的区域。
6. 点击“开始录制”。
7. 录制过程中可以滚动网页，也可以用控制面板暂停、继续或停止。
8. 点击“停止”后，视频会自动保存为 WebM 文件。

如果经常录制同一块区域，插件会自动加载上次区域，可以直接开始，也可以重新选区。

### 4. 使用网页翻译

1. 打开 WebCraft 面板，进入“翻译”页签。
2. 确认“启用翻译功能”已打开。
3. 选择触发快捷键，例如三连击空格、`Ctrl+Q`、`Alt+Q` 或 `Ctrl+E`。
4. 选择目标语言，默认是自动中英互译。
5. 在网页输入框中选中文本或输入文本，按设置的快捷键触发翻译。
6. 也可以点击网页右侧的悬浮翻译入口，打开翻译面板直接输入文本。

如果需要更高质量翻译：

1. 打开设置页。
2. 进入“翻译”设置。
3. 将翻译引擎切换为 DeepL API。
4. 填写 DeepL Auth Key。
5. 选择 DeepL Free 或 DeepL Pro 端点，也可以保持自动选择。

### 5. 使用采集画布整理资料

1. 在网页上选中文字。
2. 使用自动弹出的快捷菜单，把内容加入采集画布。
3. 遇到图片或链接时，也可以通过采集入口保存。
4. 点击网页右侧的画布按钮，打开采集画布。
5. 使用顶部筛选切换图片、文字、网页或链接。
6. 使用搜索框查找已采集内容。
7. 需要迁移采集内容时，在画布窗口中单独导出 JSON；设置页的配置备份不包含采集内容。

如果不想每次采集后自动打开画布，可以在设置页关闭“采集后自动打开画布”。

### 6. 下载 YouTube 缩略图

单个视频下载：

1. 打开 WebCraft 面板。
2. 进入“YouTube”页签。
3. 粘贴 YouTube 视频链接。
4. 点击“下载高清缩略图”。

批量下载：

1. 在“YouTube”页签中粘贴频道、列表或主页链接。
2. 选择下载数量限制：50、100、200 或 500。
3. 点击“分析并批量下载”。

在 YouTube 页面中使用：

1. 打开 YouTube 视频页、频道页或推荐列表。
2. 鼠标移到视频缩略图附近。
3. 点击插件注入的下载按钮保存缩略图。
4. 在播放器区域可使用单帧截图按钮或录制按钮。

### 7. 管理 YouTube 推荐内容

1. 打开 WebCraft 面板，进入“YouTube”页签。
2. 在“右侧推荐视频”中选择模式：
   - 开启：保持推荐区正常显示。
   - 关闭：隐藏推荐区。
   - 白名单：只显示白名单频道。
3. 如选择白名单，在文本框中每行填写一个频道名。
4. 打开设置页中的 YouTube 设置，可进一步隐藏 Shorts、直播、广告位或 YouTube 自带评论翻译按钮。

### 8. 备份和恢复配置

1. 打开 WebCraft 设置页。
2. 进入“导入导出”页面。
3. 点击“导出配置”保存 JSON 文件。
4. 在新浏览器或新电脑中安装插件后，点击“导入配置”选择该 JSON 文件。

注意：新导出的 JSON 不包含 DeepL API Key，导入后需要重新填写。旧版备份可能仍包含密钥，请不要发送给他人。

## 设置页说明

- 总览：集中打开或关闭截图、录屏、采集画布、翻译和 YouTube 模块。
- 截图和录屏：设置截图文件名模板、自定义工具名、录屏边框、最长录制时长和最大文件大小。
- 采集画布：设置悬浮按钮、采集后自动打开、选中文本快捷菜单和筛选入口。
- 翻译：设置翻译引擎、DeepL API Key、目标语言、悬浮按钮、选中文本优先和翻译历史。
- YouTube：设置缩略图文件名模板、黑名单、隐藏 Shorts/直播/广告位/评论翻译按钮。
- 导入导出：备份或恢复扩展配置。
- 更新日志：查看版本变更记录。

## 常用快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+Shift+S` | 快速截取当前可视区域 |
| `Ctrl+Q` | 打开或关闭采集画布 |
| `Alt+Shift+W` | 显示选中文本快捷菜单 |
| 三连击空格 | 默认翻译触发方式 |

macOS 下，截图快捷键为 `Command+Shift+S`，采集画布快捷键为 `Command+Shift+Y`。

## 使用建议

- 做截图凭证时，先填写清楚“名称”和“工具”，后续文件会更容易归档。
- 长截图前先让页面加载完成，特别是图片很多的页面。
- 录屏前建议关闭无关浮层，或使用插件的干净录制模式避免控制按钮进入画面。
- 翻译长文本时，如果 Google 翻译结果不稳定，可以切换到 DeepL API。
- 批量下载 YouTube 缩略图时，建议先从 50 个开始，确认结果正常后再提高数量。

## 隐私和权限说明

WebCraft 需要读取当前网页内容、截取当前标签页、下载文件、使用调试器进行全页截图、使用 tabCapture 进行录屏，并访问翻译和 YouTube 缩略图相关地址。这些权限用于实现截图、录屏、翻译、下载和资料采集功能。

扩展配置和 API Key 保存在浏览器本地扩展存储中。除调用用户选择的翻译服务外，插件不会主动上传采集画布内容。

## 常见问题

### 截图或长截图失败

- 确认截图模块没有在设置页关闭。
- 刷新网页后重试。
- 如果网页高度特别大，长截图会自动降低 DPR 以避免浏览器崩溃。
- 某些浏览器内部页面、扩展页面或受保护页面不能被 Chrome 扩展截图。

### 录屏启动失败

- 确认录屏模块没有在设置页关闭。
- 刷新页面后重新选择区域。
- Chrome 可能会限制某些页面的 tabCapture 权限，换普通网页测试。
- 如果文件达到大小上限或时长上限，插件会自动停止录制。

### 翻译没有反应

- 确认翻译功能已启用。
- 检查触发快捷键是否和网页自身快捷键冲突。
- 如果使用 DeepL，确认 API Key 有效，并检查 Free/Pro 端点是否匹配。
- 可临时切回 Google Translate 验证是否是 DeepL 配置问题。

### YouTube 按钮没有出现

- 确认 YouTube 工具没有在设置页关闭。
- 刷新 YouTube 页面。
- YouTube 页面是动态加载的，等待列表加载完成后再移动鼠标到缩略图上。
- 如果开启了推荐区白名单或隐藏规则，检查频道名、黑名单、Shorts/直播/广告位设置。

### 导入配置失败

- 确认导入的是插件导出的 JSON 文件。
- 不要手动删除 JSON 中的 `settings` 字段。
- 如果导入后页面没有立即变化，刷新当前网页或重新打开插件面板。
