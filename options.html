开关总览

集中控制插件里的主要模块。关闭后，对应入口会停用，页面脚本也会尽量停止工作。

截图和区域录屏

截图、长截图、区域录屏和软件/工具名称统一在这里设置，和 popup 前台保持一致。

可在 Chrome 扩展快捷键里给「开始/停止自动截图」分配快捷键。

内置选项仍会保留：Midjourney生成、Firefly生成、购买Gemini生成、Flow Ultra版、Flow Pro版。

采集画布

控制画布是否自动弹出，以及顶部显示哪些分类入口。

翻译增强

管理翻译引擎、目标语言、选中文本、历史记录和常用短语。

YouTube

控制 YouTube 辅助工具、推荐过滤、缩略图命名和评论翻译按钮。

导入导出配置

换电脑或重新安装前，先导出一次配置。导出文件不包含 API Key、翻译历史和采集画布；换设备后需重新填写密钥。

版本和更新日志

记录这套工具最近做过什么，后续排查也方便。

1.8.3

  • 采集画布、浮动翻译和选中文字译文改在独立扩展窗口显示，避免网页读取内容或嵌入面板。
  • 配置备份仅导出已知设置，默认排除 API Key、翻译历史和采集画布；导入时忽略未知字段。
  • 采集画布下载数据链接时校验图片类型，并在保存网页完成后反馈结果。

1.8.2

  • 更新 jsPDF 至 4.2.1，修复已公开的依赖漏洞。
  • 翻译快捷键跳过密码、验证码和支付输入框，并阻止网页脚本伪造操作触发剪贴板读取与翻译；配置导出不再包含 API Key。
  • 截图与录屏请求绑定来源标签页，并固定发布工作流使用的 Action 提交。
  • 采集画布和浮动翻译迁入扩展页面，避免网页脚本读取面板内容；发布工作流升级至受支持的 Action 主版本。

1.8.1

  • 新增自动截图循环：每次保存可视区截图后自动按左/右方向键切换到下一张。
  • 自动截图支持 4-10 秒间隔和左/右方向设置，并可在 Chrome 扩展快捷键中分配开始/停止快捷键。

1.7.3

  • 翻译目标语言新增波兰语、瑞典语、马扎尔语、克罗地亚语、保加利亚语等更多选项。
  • 新增右侧画布悬浮按钮、右侧浮动翻译按钮和选中文字快捷菜单开关。
  • 选中文字快捷菜单支持关闭自动弹出，并可通过快捷键按需呼出。

1.7.2

  • 恢复 YouTube 各类列表和推荐区的缩略图下载按钮。
  • 调整 YouTube 侧边快捷按钮图标，保持截图、录制和下载入口更直观。
  • 补充 WebCraft 维护规则，记录发布、编码和回归检查注意事项。

1.7.1

  • 修复编码污染导致的翻译浮窗、录屏面板和 YouTube 录制按钮乱码。
  • 修复浮动翻译面板无法打开的问题。
  • 修复区域录屏变量声明被注释吞掉后无法启动的问题。

1.7.0

  • 采集画布新增网页收藏类型，可保存当前网页标题、链接、域名、摘要和选中文本。
  • 采集画布新增类型筛选：全部、图片、文字、网页、链接。
  • 设置页调整为“截图和录屏”“采集画布”等独立页面，并清理乱码文案。

1.6.9

  • 修复 CodeQL 提示的 URL 协议和域名校验问题，收紧采集链接、YouTube 页面判断和批量下载入口。

1.6.8

  • 新增 YouTube 单帧截取和视频录制侧边按钮。
  • 区域录屏新增干净录制模式，避免导出视频带红框和控制按钮。
  • 新增“采集后自动打开画布”开关。
